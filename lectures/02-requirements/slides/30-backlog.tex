\section{Backlog}

\begin{frame}{Что такое backlog}
  \lead{Упорядоченный список ещё не сделанной работы.} Не канбан \flqq для галочки\frqq.

  \medskip
  \begin{itemize}\setlength\itemsep{0.4em}
    \item Выше --- раньше и важнее для MVP; ниже --- можно отложить.
    \item Для этой практики основные элементы backlog --- user stories с AC.
          В общем случае backlog также может содержать баги,
          технические задачи и исследования.
    \item Deliverable курса: Markdown в Git (\texttt{BACKLOG.md} или \texttt{docs/backlog.md}).
    \item Issues и Jira --- индустриальный аналог. Для сдачи не обязательны.
  \end{itemize}
\end{frame}
