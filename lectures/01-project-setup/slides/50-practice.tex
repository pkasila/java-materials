\section{Практика и Proposal}

\begin{frame}{Практическое задание}
  \lead{Каркас проекта, не лабораторная на Manytask2.}
  До следующей пары соберите репозиторий, а не доменную логику.

  \medskip
  \begin{enumerate}\setlength\itemsep{0.4em}
    \item Личный Git-репозиторий проекта на GitHub или GitLab.
    \item Gradle-проект с Kotlin DSL и \textbf{закоммиченным wrapper}.
    \item Файл \texttt{.gitignore} (сборка, кэш IDE --- вне Git).
    \item README: тема, как собрать, какая JDK.
    \item Успешная сборка: \texttt{./gradlew build}.
  \end{enumerate}
\end{frame}
